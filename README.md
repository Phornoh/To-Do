# แอปรายการสิ่งที่ต้องทำ (Thai Todo)

React + Vite + Tailwind CSS v4 + lucide-react

## เริ่มใช้งาน
```bash
npm install
npm run dev      # เปิดโหมดพัฒนา
npm run build    # สร้างไฟล์ production ไว้ที่ dist/
npm run preview  # ทดลองเปิดไฟล์ที่ build แล้ว
```
ข้อมูลเก็บใน React state เท่านั้น (รีเฟรชแล้วหาย) ไม่ใช้ localStorage
